# Preserving the Joy of Driving

This repository contains supplementary material for the paper:

**“Preserving the Joy of Driving”**

Published in the ACM Digital Library:  
https://doi.org/10.1145/3828158.3838230

## Contents

The repository includes the data and materials used for the analyses presented in the paper:

- `Qualitative data + Personality Score.xlsx`
- `Testing - UEQ.xlsx`
- `UX-Curve.xlsx`

These files are provided as supplementary material to support transparency and reproducibility of the reported results.
